Tự Động Hóa Xuất Bản Bài Viết Bằng n8n

Cấu hình API Key và Endpoint trong Node HTTP Request của n8n để tự động nhận bài viết từ AI (ChatGPT, Claude, Perplexity...)

http://localhost:3000/api/posts
Đang tải...

Cấu trúc JSON Body mẫu cho Node HTTP Request trong n8n: 

{
  "title": "={{ $json.title }}",
  "excerpt": "={{ $json.excerpt }}",
  "content": "={{ $json.content_html }}",
  "category": "Performance Ads", // hoặc "Brand Strategy", "Trade Marketing", "Data Analytics", "E-Commerce"
  "cover_image": "assets/images/portfolio-banner.jpg",
  "read_time": "5 phút đọc",
  "tags": "AI, Marketing, Automation",
  "status": "published"
}

Lệnh cURL kiểm tra nhanh: 

curl -X POST http://localhost:3000/api/posts \
  -H "Content-Type: application/json" \
  -H "x-api-key: [API_KEY]" \
  -d '{"title":"Test bài viết từ n8n","content":"<h2>Thành công</h2><p>Bài viết đã lên CMS!</p>","category":"Performance Ads"}'

Xác Thực 2 Bước (2FA)

CHƯA BẬT

Bảo vệ tài khoản bằng mã OTP 6 số theo thời gian thực (Google / Microsoft Authenticator)

Khi kích hoạt, mỗi lần đăng nhập ngoài mật khẩu bạn sẽ cần nhập thêm mã 6 chữ số từ ứng dụng bảo mật trên điện thoại.

Hỗ trợ: Google Authenticator, Microsoft Authenticator, Authy, Apple Passwords.
Kèm 5 mã dự phòng khôi phục phòng khi mất điện thoại.

Anti-Bot & Chống Dò Pass

ĐANG BẢO VỆ

Chủ động ngăn chặn tấn công tự động và dò quét mật khẩu

Khóa IP Tự Động (Brute-Force Lockout)
Nhập sai quá 5 lần trong 15 phút sẽ tự động khóa địa chỉ IP và tài khoản trong 15 phút.
Bẫy Bot Honeypot Tàng Hình
Trường ẩn vô hình với con người nhưng thu hút bot tự động, ngay lập tức chặn đứng tool cào.
Thuật toán Hash SHA-256 + Salt 128-bit
Chống tấn công Rainbow Table và Timing Attack (hash_equals).
